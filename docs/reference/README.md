# Referensi lama

`cashly-frontend.nginx.conf` berasal dari file Nginx frontend Cashly yang ikut
tersalin ke repo ini. File dipertahankan sebagai referensi asal, bukan sebagai
konfigurasi reverse proxy Evolution. Domain/port di dalamnya perlu diverifikasi
di repo frontend sebelum digunakan.

Setup Evolution awal memakai localhost dan SSH tunnel sesuai
[panduan instalasi](../setup-evolution.md); tidak memuat file Nginx ini.
